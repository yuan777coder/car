# 接下来要做的事（详细操作过程）

按顺序执行，每一步都有「判断标准」。**任何一步不过关，不要跳到下一步。**

---

## 阶段 0：硬件核对（上电前，约 1 小时）

### 0.1 逐项核对接线

对照 `docs/pinmap.md` 的表，用万用表/原理图确认：

| 检查项 | 接法 | 错了会怎样 |
|--------|------|-----------|
| 电感 ×7 → 运放 → ADC | P0.0~P0.6，经 RS824 调理后是**直流电压**（0~参考电压） | 采到值不对/恒 0 |
| **ADC_VREF+** | **必须接基准（如 3.3V），不能悬空** | 读数漂移或不变 |
| 电机L PWM/方向 | P1.0 / P1.1 | 不转/反转 |
| 电机R PWM/方向 | P1.2 / P1.3 | 同上 |
| 舵机 | P2.0 | 不动/乱跳 |
| OLED | P2.4(SCL)、P2.5(SDA)，带 4.7~10k 上拉 | 花屏/黑屏 |
| 串口 | P3.0(RX)、P3.1(TX) 接 USB-TTL | 无输出 |
| 按键 ×4 | P3.2/3.3/3.6/3.7，按下接地 | 无响应 |
| 编码器（可选） | P3.4/P3.5 A 相，P4.0/P4.1 B 相 | 测速为 0 |

### 0.2 电感传感器本身

- 工字电感 **10mH**，谐振电容 **6.8nF**（或 5.6nF+560pF），谐振点 19.8~20.2kHz。
- 相邻电感间距 **≥2cm**（防互感），左右严格对称（高度、倾角一致），离地 **10~15cm**。
- 横竖电感别贴太近（防谐振，会导致直道上竖电感也有值）。

### 0.3 准备工具

- USB-TTL（串口）、串口助手（或 `python tools/scope.py`）、STC-ISP 下载器、示波器/逻辑分析仪。

## 阶段 1：建 Keil 工程（约 1 小时）

详见 `docs/keil_setup.md`，关键点复述：

1. Keil uVision → Project → New，芯片选 **STC32G144K246**。
2. **不勾选** "添加 STARTUP 文件"。
3. 用 STC-ISP 的「头文件」功能生成芯片头文件，放进工程目录。
   - 若生成的是 `STC32G144K246.H`（不是 `STC32G.H`），把 `src/main.c` 里的
     `#include "STC32G.H"` 改成 `#include "STC32G144K246.H"`。
4. 把 `src/` 下**所有 `.c`**（含 bsp/drivers/algo/app 子目录）加入工程。
5. Options → C251 → Include Paths 加：
   ```
   src
   src/bsp
   src/drivers
   src/algo
   src/app
   ```
6. Options → Target：**Memory Model = Large**，**Code Rom Size = Huge**。
7. 编译，目标 **0 Error**。有报错先贴出来解决（大概率是头文件名或中断宏名）。

> 判据：Build 输出 `0 Error(s)`。

---

## 阶段 2：首次下载 + 最小系统验证（约 30 分钟）

1. STC-ISP 打开编译出的 HEX。
2. 下载参数：
   - 芯片：STC32G144K246
   - **IRC 频率：24MHz**（必须与 `board_config.h` 的 `MAIN_FREQ_MHZ` 一致）
   - **关闭「下载时擦除用户 EEPROM」**
   - EEPROM 大小：分配一段（如 4KB）
   - WTST 初值：让 STC-ISP 按 24MHz 自动设置
3. 下载后接串口，115200 8N1，复位。

**判据（两条都满足才算过）：**
- 串口打印：
  ```
  == EM CAR READY ==
  param: DEFAULT (need calibrate & save)
  ```
- OLED 点亮，显示 MAIN 页面（IND / DEV / SRV / SPD / TGT / EL / MODE）。

> 串口无输出 → 查 P3.0/P3.1 接反没有、USB-TTL 的 TX/RX 交叉、`MAIN_FREQ_MHZ` 对不对。
> OLED 黑屏 → 查 I2C 上拉、地址（模块背面是 0x3C 还是 0x3D，0x3D 时改 oled.c 的 `OLED_ADDR` 为 0x7A）、
> 以及 `soft_i2c.c` 的 `I2C_DELAY_US` 调大到 4~5 试试。

---

## 阶段 3：电感 ADC 通道验证（约 30 分钟，**电机/舵机此时不接或断电**）

目的：确认 7 路电感信号能正确采进来。

1. 串口发 `text`，观察回传里的 `N0 N1 N2 N3 N4`（水平 5 路归一化）和 `SUM`。
2. 或 K2 翻到 **ADC 页**，看 7 通道 RAW / NRM。
3. 用一段通 20kHz 电流的导线（赛道信号源）靠近每个电感，看对应通道数值**明显变大**。

**判据：**
- 每个电感靠近导线时，对应通道 RAW 值上升、NRM 上升。
- 没接/坏的电感：RAW 一直很低且 NRM 恒 0。

> 某通道恒 0 → 查该路运放是否输出、ADC 通道号是否对应正确。
> 所有通道都飘/不变 → 查 **ADC_VREF+ 是否悬空**。
> 想更直观：串口发 `scope`，用 `python tools/scope.py -p COMx` 看 N0~N4 波形（通道号见脚本说明）。

---

## 阶段 4：归一化标定（约 10 分钟）

1. 把车放赛道上，串口发 `cal`（或按 K3）。
2. **沿赛道推车走一圈**（6 秒内），让每个电感都经历「远离导线」和「正对导线」两种状态。
3. 6 秒后自动结束：OLED 显示 `CALIB SAVED`，串口打印 `calib done, saved`。
4. 验证：K2 到 STATUS 页，`PARAM` 应显示 `EEPROM`、`CALIB` 显示 `LOADED`。

> 判据：STATUS 页 PARAM=EEPROM 且 CALIB=LOADED；重新上电后仍保持（说明 EEPROM 读写正常）。
> 若上电又变 DEFAULT → 查 STC-ISP「下载时擦除 EEPROM」是否还勾着，或 EEPROM 大小分配。

---

## 阶段 5：舵机中值 + PD 调试（约 1~2 小时）

### 5.1 先标机械中值

1. 只接舵机（电机可断开），上电。舵机应转到**大致中位**。
2. 若中位明显偏（前轮不正）：
   - 机械上：把舵盘/拉杆调正（首选）。
   - 或串口 `trim=±N` 微调，`save`。
3. 用串口 `?` 看当前参数确认。

### 5.2 验证方向

- 串口发 `run`，用手把车头往左偏（或模拟导线在右侧），舵机应**向右打**。
- 方向反了：改 `config.h` 的 `SERVO_DIR`（或 `DEV_DIR`）符号，重新编译。

### 5.3 调 PD（低速起步）

先在很低速度下试，只调舵机：

```
base=250          # 低速
kp=500            # 从默认 700 往下试，先稳
kd=40
run
```

观察现象 → 调整：

| 现象 | 调整 |
|------|------|
| 直线上左右摆动 | `kp` 太大，减（如 kp=400） |
| 入弯转不够、冲外道 | `kp` 太小，增 |
| 过弯后在直线上来回晃 | `kd` 太小，增 |
| 直线上抖舵（高频小抖） | `kd` 太大 或 增大 `DEV_DEADZONE` |

调好 `save`。

> 判据：车能稳跑直线 + 平滑过缓弯，不摆动不冲出。

---

## 阶段 6：电机方向 + 速度验证（约 30 分钟）

1. 接上电机，`run` 看两轮**同向、前进**。
2. 反了 → 改 `config.h` 的 `MOTOR_REVERSE_L/R` 对应位置 1，重新编译（别改电机线）。
3. 调速度：
   ```
   base=400          # 开环占空比‰
   min=220           # 弯道最低速度
   max=900
   ```
4. 弯道减速由 `SPD_CURVE_START`/`SPD_CURVE_ENABLE` 控制，先保持默认。

> 判据：直道跑得动、弯道能明显减速、不冲出。

---

## 阶段 7：整车联调（持续迭代，重点）

现在舵机 + 电机一起上，反复调。核心顺序：**先舵机（稳循迹），再提速**。

1. 低速 `base=250~350` 跑整圈，确认不丢线、不出赛道。
2. 逐步提 `base`，每提一档重新调 `kp/kd`。
3. 用 `scope` 看 DEV（偏差）和 SRV（舵机）波形：DEV 应光滑、过弯不饱和（<±1000）。
4. 若接编码器：`ENCODER_ENABLE=1`，`pikp/piki` 调速度环。

> 判据：目标速度下能连续跑 N 圈稳定不冲出。

---

## 阶段 8：元素识别（可选，最后做）

1. 默认 `ELEMENT_ACTION_ENABLE=0`（只识别不干预），先把 `scope` 切出来看竖直电感
   （通道 VL/VR）和总强度 `SUM` 过圆环/十字时的波形。
2. 照着波形改 `config.h` 的 `EL_*` 阈值。
3. 确认判据可靠后，再把 `ELEMENT_ACTION_ENABLE=1` 让它真正参与决策。

> 判据：OLED 的 EL 字段、串口 EL 字段在过元素时正确变化且不误报。

---

## 阶段 9：参数固化

- 每次调好一组参数，串口发 `save`（或按 K4）写 EEPROM。
- 需要恢复出厂：串口 `default`（或 K1 长按）。

---

## 关键串口命令速查

```
?                查看当前参数
kp=700 kd=60     舵机 PD
trim=0           舵机中值微调
base=400 min=220 max=900   速度
pikp=30 piki=4   速度环 PI（编码器）
cal / run / stop 标定/启动/停止
scope / text     波形/文本
save / load / default
page=N           翻显示页
```

## 两个必须上车实测确认的点

1. **PWM 频率**：示波器测 P1.0，若 20kHz 变 10kHz → `pwm.c` 里 `clk` 处除以 2。
2. **EEPROM 基址**：若 `save` 后掉电丢参数，先别擦写，改用「读」验证基址
   （`EEPROM_BASE_ADDR` 在 `board_config.h`），必要时改成绝对地址。
